🍔 FoodHub - Food Delivery Web Application

FoodHub is a full-stack food delivery web application that allows users to explore restaurants, browse menus, add food items to their cart, manage favourites, place orders, and manage their profile.

✨ Features

- 🏠 Modern and responsive homepage
- 🍽️ Browse restaurants and menus
- ❤️ Add and manage favourite food items
- 🛒 Shopping cart with quantity management
- 🔐 User registration and login
- 👤 User profile management
- 📍 Delivery address and checkout
- 💳 Payment and order placement
- 📦 Order success confirmation
- 📜 Order history
- 🤖 Interactive FoodHub chatbot

🛠️ Technologies Used

Frontend
- HTML
- CSS
- JavaScript
- JSP

 Backend
- Java
- Jakarta Servlets
- JDBC

Database
- MySQL

Server
- Apache Tomcat 10

Development Tools
- Eclipse IDE
- JDK 21
